# Rust Distributed Routing

A small distributed routing project built in Rust.

## Overview

This project implements a simple distributed routing system in Rust. It focuses on routing requests between multiple backend nodes and keeping the implementation small enough to understand and experiment with.

## Features

- Request routing between backend nodes
- Basic distributed routing logic
- Asynchronous networking with Tokio
- Simple and lightweight implementation

## Project Structure

```text
rust-distributed-routing/
├── src/
│   └── main.rs
├── Cargo.toml
└── README.md
```

## Running

```bash
cargo run
```

## Testing

```bash
cargo test
```

## Notes

This is a small learning project focused on Rust networking and distributed-systems concepts. The goal is to keep the implementation straightforward while providing a base for experimenting with routing, backend communication, and failure handling.
